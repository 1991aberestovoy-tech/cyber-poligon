# Киберполигон: 30 заданий за час

Статическое веб-приложение для школьного CTF-турнира по кибербезопасности.

## Что внутри

- 30 заданий разной сложности в одном последовательном маршруте.
- Полное прохождение рассчитано примерно на 60 минут.
- Категории: Web, Crypto, Stego, Forensics, OSINT, SOC, Detection, Network, Linux, DevSecOps и Incident Response.
- Без регистрации и сервера.
- Прогресс хранится только в браузере участника.
- Есть таймер, баллы, финальный профиль и подсказки по направлениям в кибербезопасности.

## Как запустить

Откройте `index.html` в браузере.

## Как сделать QR-код

1. Загрузите папку на статический хостинг: GitHub Pages, Netlify, Vercel, школьный сайт или внутренний сервер.
2. Скопируйте публичную ссылку на `index.html`.
3. Создайте QR-код на эту ссылку любым генератором QR.
4. Перед мероприятием проверьте ссылку с телефона в той же сети, где будут школьники.

## Рекомендация для занятия

Дайте участникам около 60 минут на прохождение, затем 5-10 минут на обсуждение:

- какие задания были самыми сложными;
- какие роли показались интересными;
- где в реальной жизни встречаются Base64, метаданные, сигнатуры файлов, логи, cookie, JWT, IDOR, YARA, SUID и секреты в контейнерах.


## Смена 2 · «Глубокий слой»

Переключатель «Смена 1 / Смена 2» находится в шапке. Смена 2 — 40 заданий повышенной сложности на 120 минут:
лаборатория изображений (каналы, битовые плоскости, уровни, XOR двух картинок, QR), hex-просмотр, спектрограмма WAV,
эмулируемый терминал (grep, git, curl, sudo, docker, awk…), шифры, RSA, хэши и «Инструменты аналитика» (кодировки, математика, песочница JS/Brainfuck).
Прогресс каждой смены хранится отдельно. Ответы хранятся только в виде SHA-256 хэшей, флаги терминальных сценариев зашифрованы.

**Запуск:** лаборатории изображений нужен http(s), поэтому открывайте через GitHub Pages или локально:
`python3 -m http.server 8000` и затем `http://localhost:8000`.

Файлы: `shift2-missions.js` (задания), `shift2-core.js`, `shift2-blocks.js`, `shift2-terminal.js`, `shift2-tools.js`, `shift2.css`, `assets/shift2/`.
Ключи ответов (`ctf-answer-key-shift2.md`) и генераторы в репозиторий не кладите.
